
# Python Week 4 Assignment: Functions and Parameters

## Files

- welcome.py: Contains a welcome() function that returns greeting messages for different people.
- toolbox.py: Contains three functions: double(), is_pass(), and greet().

## Reflection

The hardest function to write was greet() because it uses a default parameter. I learned that a function can use a default greeting when no greeting is provided, or accept a different greeting when one is given.
